# Security Policy for `<OWNER>/<REPO>`

## Supported Versions

The latest tagged release (`<version>`) is supported. Fixes land on `main` and
ship in the next tag.

## Reporting a Vulnerability

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/<OWNER>/<REPO>/security/advisories/new).
Do not open a public issue. Include the affected component, expected versus
actual behavior, and reproduction steps.

## Scope

- `<project-specific scope bullet>`
- Vulnerabilities in upstream software this repository packages belong with
  that upstream project.

## What to Expect

This project has one maintainer. Expect acknowledgement within a week, followed
by a fix or written assessment. There is no bounty. Reports are credited in the
changelog unless you decline.
